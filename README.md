## ✨ 功能特性

### 🎲 双模式生成

| 模式 | 图标 | 说明 |
|------|------|------|
| **随机模式** | 🎲 | 使用预设词库自动生成名称，无需填写任何文字 |
| **填字模式** | ✏️ | 输入基础名称（如"创新路"），系统围绕它生成关联名称 |

### 📚 支持设施类型（8种）

```
🏘️ 区域地名  │  🚇 地铁站  │  🚌 公交站  │  ✈️ 机场
🏥 医院      │  🚂 火车站  │  🚄 高铁站  │  🛣️ 道路
```

### 🌏 地域风格（6种）

| 地域 | 风格特点 | 示例名称 |
|------|----------|----------|
| 🌊 **滨海城市** | 海洋、海湾、潮水元素 | 临海、望潮、沧湾、云汐 |
| ❄️ **北方城市** | 大气、厚重、政治感 | 长安、北辰、清河、永定 |
| 🌸 **江南水乡** | 婉约、诗意、自然 | 青溪、荷塘、柳岸、听雨 |
| 🏔️ **山地城市** | 山岭、峰谷、自然 | 岚山、云岭、青峰、龙门 |
| 🏙️ **现代新区** | 科技、创新、未来 | 星河、智谷、科创、云栖 |
| 🏛️ **历史古城** | 古朴、传统、历史感 | 古城、文昌、永宁、凤仪 |

### ⚙️ 智能参数控制

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| **字数控制** | 2-6字 | 3字 | 控制生成名称的目标字数（如3字=科创路） |
| **关联度** | 0%-100% | 80% | 控制生成名称与关键词的相似度 |
| **词库混合** | 0%-100% | 100% | 系统字库与用户字库的混合比例 |
| **生成数量** | 4-24个 | 12个 | 一次生成的名称数量 |

### 🎨 多主题切换

| 主题 | 图标 | 配色 | 适用场景 |
|------|------|------|----------|
| **系统主题** | 🎨 | 蓝紫色渐变 | 默认主题，视觉舒适 |
| **浅色主题** | ☀️ | 白灰蓝清爽 | 适合白天使用 |
| **深色主题** | 🌙 | 深灰黑蓝 | 适合夜间使用，保护视力 |

### 📚 词库管理

- 📖 **系统字库查看**：浏览内置的6种地域、8种类型的完整词库（只读）
- 👤 **用户字库查看**：查看已导入的自定义词汇
- 📥 **多格式导入**：支持 JSON、TXT、CSV 三种格式批量导入
- 🔄 **词库混合**：可调节系统字库与用户字库的混合比例（0%-100%）

### 🛡️ 内容安全

- ✅ **中英文检测**：仅支持中文输入，英文将被自动过滤
- ✅ **敏感词过滤**：自动过滤国家设施、脏字、政治敏感词汇
- ✅ **字数限制**：自动过滤不符合字数要求的词汇

### 📤 导出功能

| 导出类型 | 说明 |
|----------|------|
| 📋 **导出收藏** | 导出已收藏的名称列表 |
| 📊 **导出当前结果** | 导出本次生成的所有名称 |
| 📤 **全部导出** | 导出收藏 + 当前结果 |

### 📌 收藏功能

- ⭐ 点击名称右上角的☆可收藏/取消收藏
- 📌 收藏列表点击名称可查看详情
- 🗑️ 支持删除收藏或清空全部收藏
- 💾 收藏数据本地存储，刷新后依然存在

### 🔍 详情弹窗

点击任意名称可查看详情弹窗，包含：📋 复制名称（一键复制名称到剪贴板）、📊 基本信息（地域、类型、关联度、基础名称）、🔗 关联设施（显示相关的地铁、公交、道路等）、💡 关联度说明（根据关联度自动显示解释文字）。

## 🚀 快速开始

### 环境要求

- **浏览器**：Chrome 60+、Firefox 55+、Safari 12+、Edge 79+
- **操作系统**：Windows、macOS、Linux 均可
- **网络**：离线可用，无需网络连接

### 本地运行

**方法一：直接打开**

下载或克隆项目到本地，用浏览器直接打开 index.html 文件。Windows 双击 index.html，macOS 右键选择打开方式选择 Safari 或 Chrome，Linux 右键选择打开方式选择 Firefox 或 Chrome。

**方法二：使用本地服务器（推荐）**

使用 Python 启动本地服务器，运行命令 python -m http.server 8080。或使用 Node.js 的 http-server，运行命令 npx http-server。然后在浏览器访问 http://localhost:8080。

**方法三：VS Code Live Server**

安装 VS Code，安装 "Live Server" 插件，右键 index.html 选择 Open with Live Server。

## ⚙️ 使用说明

### 1. 基础生成

步骤1：选择生成模式（随机/填字）；步骤2：选择设施类型（全部/地铁/公交/...）；步骤3：选择地域风格（滨海/北方/...）；步骤4：调整参数（字数/关联度/数量）；步骤5：点击「立即生成名称」。

### 2. 填字模式

输入框示例：✅ "创新路" → 生成关联的创新中路、创新园等；
❌ "Innovation" → 包含英文，将被过滤；❌ "中南海路" → 包含敏感词，将被过滤。

### 3. 参数调节

**字数控制**：2字为科创、创新；3字为科创路、创新园；4字为创新中路、科创大道；5字为科创大道东；6字为科创大道东路。

**关联度**：100%为高度相似，保留关键词核心部分；80%为较相似，部分保留关键词元素；50%为中等相似，少量保留关键词元素；20%为较低相似，几乎不同；0%为完全不相关，独立生成。

**词库混合**：100%为完全使用系统内置字库；50%为系统字库与用户字库各取一半；0%为完全使用用户导入的自定义字库。⚠️ 未导入用户字库时，此滑块不可用。

### 4. 快捷操作

| 操作 | 快捷键/方式 |
|------|-------------|
| 快速生成 | 点击输入框后按 Enter 键 |
| 关闭弹窗 | 点击遮罩层或按 Escape 键 |
| 复制结果 | 点击「复制全部」按钮 |
| 收藏名称 | 点击名称卡片右上角的☆ |
| 查看详情 | 点击名称卡片 |

## 📚 词库管理

### 打开词库管理

点击顶部工具栏的「📚 词库」按钮打开词库管理面板。

### 系统字库查看

📖 选择地域类型（6种）；📖 选择名称类型（8种）；📖 实时显示对应词库内容；⚠️ 系统字库为只读内容，不可编辑。

### 用户字库查看

👤 显示所有已导入的自定义词汇；👤 按类型分组展示；⚠️ 未导入时显示提示信息。

### 导入词库

**支持格式**

**1. JSON格式（推荐）**

```json
{
  "coastal": {
    "metro": ["星海", "云港", "蔚蓝"],
    "road": ["滨海大道", "观海路", "听涛路"]
  },
  "modern": {
    "place": ["智谷", "科创园", "未来城"],
    "metro": ["科技园", "创新路", "数字港"]
  }
}
```

**2. TXT格式（每行一个词）**

```
新词1
新词2
新词3
```

**3. CSV格式（逗号分隔）**

```
新词1,新词2,新词3
```

**导入步骤**

1. 选择地域类型（6种）；2. 选择名称类型（8种）；3. 粘贴词库内容；4. 点击「导入词库」按钮；5. 查看导入结果提示。

**导入规则**

✅ 仅支持中文词汇；✅ 字数范围：1-6字；✅ 敏感词自动过滤；✅ 重复词汇自动去重；✅ 导入后自动保存到本地。

## 🛡️ 内容安全

### 中英文检测

仅支持中文输入。✅ "创新路" → 允许生成；❌ "Innovation" → 自动过滤；❌ "创新Road" → 自动过滤。

### 敏感词过滤

过滤类别：国家设施（中南海、天安门、白宫、国会等）；政府机构（国务院、国防部、军事基地等）；政治敏感（反动、分裂、独立等）；脏字辱骂（各类不文明词汇）。

### 过滤规则

| 场景 | 处理方式 |
|------|----------|
| 填字输入 | 包含敏感词/英文时，提示错误，不生成 |
| 词库导入 | 敏感词/英文词汇自动过滤，不导入 |
| 生成结果 | 敏感词汇自动过滤，不显示 |

## 🐛 常见问题

### Q1: 生成的名称不真实怎么办？

**A1**: 尝试以下方法：调整关联度至80%-100%；切换不同的地域风格；使用填字模式输入更具体的关键词。

### Q2: 为什么我不能输入英文？

**A2**: 本生成器专为中国地名设计，英文输入将被自动过滤。如需生成英文地名，需要修改 `js/utils.js` 中的 `containsEnglish()` 函数。

### Q3: 词库混合滑块为什么是灰色的？

**A3**: 需要先导入用户字库才能使用词库混合功能。点击「📚 词库」→「📥 导入字库」→ 导入自定义词汇。

### Q4: 收藏的名称刷新后还在吗？

**A4**: 是的，收藏数据保存在浏览器的 `localStorage` 中，刷新后依然存在。但清除浏览器数据会丢失。

### Q5: 导入词库后不生效怎么办？

**A5**: 检查以下内容：词库格式是否正确（JSON/TXT/CSV）；是否包含中文词汇；字数是否在1-6字范围内；是否包含敏感词。

### Q6: 主题切换后刷新恢复了默认怎么办？

**A6**: 主题选择会自动保存。如果刷新后恢复默认，可能是浏览器隐私模式或存储被清除。

### Q7: 移动端使用体验如何？

**A7**: 项目已做响应式适配，支持移动端使用。建议在移动端使用Chrome或Safari浏览器。

### Q8: 可以离线使用吗？

**A8**: 可以。项目无任何外部依赖，下载到本地后可完全离线使用。
